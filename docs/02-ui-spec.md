# 02. UI 仕様

## 1. 画面構成

画面は 3 領域で構成する。

1. **ヘッダー** (1 行): 左にモードとリポジトリ情報、右に表示中ファイルのパス
2. **ボディ**: 左ペイン (ツリー) + 右ペイン (内容 / 差分)
3. **ステータスバー** (1 行): ブランチ、変更ファイル数、カーソル位置、既定と異なる状態 (`[unified 折返 種別順 staged↔HEAD]`)、主要キーヒント

ステータスバーは元の要求スケッチには無いが、変更件数とキーヒントの提示に必要と判断して追加した。不要なら設定で非表示にできるようにする。

### 1.1 tree モード

```
┌────────────────────┬───────────────────────────────────────────────────┐
│ TREE  my-project   │ src/app/state.rs                                  │
├────────────────────┼───────────────────────────────────────────────────┤
│ ▾ src/             │   1 use std::path::PathBuf;                       │
│   ▾ app/           │   2                                               │
│  M    state.rs     │   3 pub struct AppState {                         │
│  A    view.rs      │   4     pub root: PathBuf,                        │
│       mod.rs       │   5     pub mode: Mode,                           │
│ ▸ tests/           │   6 }                                             │
│ M Cargo.toml       │   7                                               │
│ ? notes.md         │                                                   │
├────────────────────┴───────────────────────────────────────────────────┤
│ main ● 3 changed   5:12   [Tab] pane  [m] diff  [/] search  [?] help    │
└────────────────────────────────────────────────────────────────────────┘
        3                              7
```

### 1.2 diff モード

```
┌────────────────────┬─────────────────────────┬─────────────────────────┐
│ DIFF  my-project   │ src/app/state.rs                    +12 -4        │
├────────────────────┼─────────────────────────┼─────────────────────────┤
│ M src/app/state.rs │   1 use std::path::Pat… │   1 use std::path::Pat… │
│ A src/app/view.rs  │   2                     │   2                     │
│ M Cargo.toml       │   3 pub struct AppSta…  │   3 pub struct AppSta…  │
│ ? notes.md         │ - 4     pub root: Str…  │ + 4     pub root: Pat…  │
│                    │                         │ + 5     pub mode: Mode  │
│                    │   5 }                   │   6 }                   │
├────────────────────┴─────────────────────────┴─────────────────────────┤
│ main ● 3 changed   hunk 1/4   []c] next  [z] fold  [r] reload  [?] help │
└────────────────────────────────────────────────────────────────────────┘
        5                    7.5                       7.5
```

左側が HEAD の内容、右側が作業ツリーの内容。行番号はそれぞれの側の実際の行番号を表示し、対向側に対応行が無い場合は空欄にする。

### 1.3 レイアウト比率

全体を 20 とした値で持つ。当初の要求は 3:7 だったが、広い端末では左ペインが余るため既定を 5:15 (= 1:3) に狭めた。

| モード | 左ペイン | 右ペイン |
| --- | --- | --- |
| tree | 5 | 15 |
| diff | 5 | 7.5 : 7.5 (右ペインを 2 等分) |

ratatui では外側を `Constraint::Fill(5)` / `Constraint::Fill(15)` で分割し、diff モードのみ右側をさらに `Constraint::Percentage(50)` × 2 で分割する。左右の比率はキー操作 (`<` / `>`) で 1/20 刻みに調整でき、調整値はセッション内で保持する。設定は `ui.tree_ratio` (1〜16)。

### 1.4 縮退表示

| 端末幅 | 挙動 |
| --- | --- |
| 120 桁以上 | 上記の通常表示 |
| 80〜119 桁 | side-by-side を維持。行番号列を 1 つに統合 |
| 80 桁未満 | 左ペインを自動的に隠す (`Tab` で一時表示)。差分は unified 表示へ自動切替 |

## 2. ツリーペイン

### 2.1 tree モード

- ファイルシステムを反映。ディレクトリはノード展開時に読み込む (遅延展開)
- `.gitignore` / `.ignore` を尊重し、対象は既定で非表示。`I` キーでトグル
- `.git/` は常に非表示
- ソート順: ディレクトリ優先 → 名前昇順 (ロケール非依存のバイト順ではなく、大文字小文字を無視した比較)
- 各エントリの先頭 2 桁に Git ステータス記号を表示

### 2.2 diff モード

- 変更のあるファイルのみを含む仮想ツリーを構築する
- 既定はフラットなパス一覧表示。`T` キーでディレクトリ階層表示に切り替える (中間ディレクトリは自動的に折り畳み結合する。例: `src/app/` )
- ソート順: パス昇順。`S` キーで変更行数の降順に切り替え

### 2.3 エントリの色分け

先頭 2 桁の記号は Git の状態を、名前はファイルの種別を表す。2 つの情報を別の位置で示すことで、どちらも失わずに読める。

| 種別 | 色 | 装飾 |
| --- | --- | --- |
| ディレクトリ | 青 | 太字 |
| シンボリックリンク | シアン | 斜体 |
| 実行ファイル | 緑 | 太字 |
| ソースコード (`.rs` `.py` `.ts` …) | 橙 | |
| 設定 / データ (`.toml` `.json` `Makefile` …) | 黄 | |
| 文書 / マークアップ (`.md` `.html` `LICENSE` …) | 紫 | |
| 画像 / フォント / 音声 | 赤 | |
| アーカイブ | 暗い赤 | |
| その他 | 灰 | |

種別の判定は「リンク → ディレクトリ → 実行ビット → 拡張子」の順。実行ビットは拡張子より優先する。

### 2.4 ステータス記号

| 記号 | 意味 | 色 |
| --- | --- | --- |
| `M` | 変更 | 黄 |
| `A` | 追加 (index に追加済み) | 緑 |
| `D` | 削除 | 赤 |
| `R` | リネーム | シアン |
| `?` | 未追跡 | グレー |
| `!` | 差分計算不可 (バイナリ / サイズ超過) | マゼンタ |
| (空) | 変更なし | 既定色 |

## 3. 内容ペイン

### 3.1 tree モード (単一表示)

- 行番号 + 本文
- シンタックスハイライト適用
- 折り返しは既定オフ。`w` でトグル

### 3.2 diff モード (左右対比)

- 行の対応付けアルゴリズムは [04-diff-model.md](04-diff-model.md) を参照
- 行種別の表現

| 行種別 | マーカー | 背景 |
| --- | --- | --- |
| 変更なし | 空白 | なし |
| 削除 (左のみ) | `-` | 赤系 |
| 追加 (右のみ) | `+` | 緑系 |
| パディング (対向行なし) | なし | 薄いグレー |

- 変更ペアの行では、語単位で差異のある範囲のみを強調背景にする
- 左右のスクロール位置は常に同期する
- 既定で全行を表示する。`z` で折り畳みモード (変更箇所の前後 N 行のみ表示、N は既定 3) に切り替える。折り畳み時は省略部分に `⋯ 42 lines` の区切り行を挿入し、その行で `Enter` を押すと局所的に展開する

## 4. キーバインド

vim の操作感に寄せる。`Esc` は常にオーバーレイ / 検索状態の解除。

### 4.1 全体

| キー | 動作 |
| --- | --- |
| `q` / `Ctrl-c` | 終了 |
| `?` | ヘルプオーバーレイ |
| `m` | tree / diff モードをトグル |
| `t` / `d` | tree / diff モードを直接指定 |
| `Tab` / `Shift-Tab` | ペイン間のフォーカス移動 |
| `r` | リロード (Git 状態 + 表示中ファイル) |
| `<` / `>` | 左ペイン幅を縮小 / 拡大 |
| `u` | side-by-side / unified 表示をトグル (diff モード) |
| `w` | 行折り返しをトグル |
| `s` | 比較対象をトグル: 作業ツリー↔HEAD / staged↔HEAD / 作業ツリー↔index |
| `Esc` | オーバーレイ・検索ハイライトの解除 |

### 4.2 ツリーペイン (フォーカス時)

| キー | 動作 |
| --- | --- |
| `j` / `k` / `↓` / `↑` | 上下移動 |
| `g` / `G` | 先頭 / 末尾 |
| `Ctrl-d` / `Ctrl-u` | 半画面スクロール |
| `l` / `→` / `Enter` | ディレクトリ展開、ファイルなら内容ペインへ読み込み |
| `h` / `←` | ディレクトリを閉じる。閉じている場合は親へ移動 |
| `z` | 展開状態をトグル |
| `I` | ignore 対象ファイルの表示トグル (tree モード) |
| `T` | フラット / 階層表示トグル (diff モード) |
| `S` | 並び順トグル: パス順 / 変更種別順 (diff モード) |
| `f` / `/` | ファイル名の絞り込み入力 |

### 4.3 内容ペイン (フォーカス時)

| キー | 動作 |
| --- | --- |
| `j` / `k` | 1 行スクロール |
| `Ctrl-d` / `Ctrl-u` | 半画面スクロール |
| `Ctrl-f` / `Ctrl-b` | 1 画面スクロール |
| `g` / `G` | 先頭 / 末尾 |
| `]c` / `[c` | 次 / 前の変更箇所へジャンプ (diff モード) |
| `]f` / `[f` | 次 / 前の変更ファイルへ移動 (diff モード) |
| `z` | 全行表示 / 折り畳み表示のトグル |
| `/` | ファイル内容の前方検索 |
| `n` / `N` | 次 / 前の検索一致 |

`]c` / `[c` は vim の差分ジャンプに合わせた 2 打鍵。`Ctrl-n` / `Ctrl-p` を同義キーとして併設する。ジャンプ先は変更ブロックの先頭が画面上部から 1/4 の位置に来るよう表示する。現在の変更箇所は番号で保持し、続けて押すと次へ進む。手動でスクロールしたら保持を解除し、そのときの表示位置から探し直す。ステータスバーに `hunk 2/3` として現在位置を出す。

`z` はフォーカス位置で意味が変わる (ツリー: 展開トグル、内容: 折り畳みトグル)。当初 `za` を割り当てる案だったが、2 打鍵の前置キーを `]` `[` のみに限定するため 1 打鍵へ変更した。

`u` / `w` は表示形式の指定でありフォーカス位置に依存しない。`Ctrl-u` (半画面スクロール) と衝突しないよう、修飾キーなしの打鍵だけを拾う。`u` による unified 指定は、端末幅 80 桁未満での自動縮退 (§1.4) とは独立している。

折り返し中は行番号を 1 行目にだけ出し、続きの行は行番号の桁を空白で埋める。side-by-side では左右で折り返し行数が変わりうるため、少ない側を余白で埋めてペア行の対応を保つ。横スクロール (`h` / `l`) は折り返し中は無効。全角文字が折り返し位置をまたいで欠けないよう、桁ではなく文字の切れ目で分割する。

`S` の変更種別順は M → A → R → D → `?` の順に並べ、同じ種別内はパス順とする。差分の行数は取得時に計算していないため、変更量による並び替えは持たない。

`s` は比較対象を 3 通りで巡回する。tree モードのステータス記号も同じ対象で付くため、モードを問わず効く。切り替えると変更一覧を取り直し、選択していたファイルが新しい一覧にも居ればその選択を保つ。既定以外の対象はステータスバーに出す。

## 5. 状態遷移

```
                    ┌──────────────┐
      m / d ───────▶│  Diff モード │◀────┐
   ┌──────────────┐ └──────┬───────┘     │
   │  Tree モード │◀───────┘  m / t      │
   └──────┬───────┘                      │
          │                              │
          │  各モード内で以下の直交する状態を持つ
          ▼
   focus: Tree | Content
   overlay: None | Help | SearchInput | FilterInput
   content: Empty | Loading | Text(...) | Diff(...) | Unsupported(reason)
```

- モードを切り替えても、ツリーの選択パスは可能な限り引き継ぐ。diff モードへ切り替えた際に選択中ファイルが変更対象でなければ、先頭の変更ファイルを選択する
- `overlay` が `None` 以外のとき、4.2 / 4.3 のキーはオーバーレイ側へ送られる
- 検索 / 絞り込みの入力は打鍵ごとに結果へ反映する。目的の行を探しながら絞り込めるようにするため。`Esc` で取り消すと入力前の状態へ戻る
- 検索は大文字を含まない語なら大文字小文字を区別しない (smart case)
- `content` が `Loading` の間も入力を受け付け、ツリー操作は継続できる (NFR-03)

## 6. 配色

差分は次の 3 点で示す。1 つの手がかりに依存させない。

1. 行背景 (削除 = 赤系、追加 = 緑系)
2. 行番号欄に続くマーカー文字 (`-` / `+`)
3. 前景色。ただしシンタックスハイライトが有効な行では構文由来の色が優先される

重ね合わせの優先度は **検索一致 > 語単位差分 > シンタックスハイライト**。検索一致は背景と前景の両方を差し替え、確実に目に入るようにする。

- 24bit 色が利用可能なら差分背景に低彩度の赤 / 緑を用い、非対応時は 6x6x6 カラーキューブへ近似して 256 色へフォールバックする
- 色覚特性への配慮として、`theme.palette = "blue-orange"` で青 / 橙の代替パレットへ切り替えられる

### 6.1 シンタックスハイライト

同梱の `tdv-dark` / `tdv-light` を既定とする。syntect 付属の base16 系テーマは色を割り当てるスコープが少なく、大半のトークンが既定色のまま残るため、エディタ (Zed / VS Code の One Dark) に近い網羅度になるようスコープ規則を自前で定義した。

キーワード・型・関数・文字列・数値・コメント・演算子・区切り記号・属性・マークアップをそれぞれ別の色にし、コメントは斜体、見出しは太字にする。`theme.syntax` で syntect 付属のテーマにも切り替えられる。
